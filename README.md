### 📂 Proyek Unggulan

Beberapa proyek utama yang telah saya kembangkan dan kelola di GitHub:

1.  **[website_laporan_breakdown](https://github.com/EoxikBlaze/website_laporan_breakdown)**
    *   *Deskripsi*: Dashboard pelaporan kerusakan alat berat pertambangan (breakdown unit) PT Pamapersada Nusantara berbasis Laravel (PHP). Dilengkapi dengan penanganan data log downtime terotomatisasi per vendor dan filter kueri global untuk keamanan multi-tenancy vendor.
    *   *Teknologi*: PHP, Laravel, MySQL.

2.  **[Fermentax-Source-Code-Flutter](https://github.com/EoxikBlaze/Fermentax-Source-Code-Flutter)**
    *   *Deskripsi*: Aplikasi berbasis mobile Flutter yang terintegrasi dengan perangkat keras IoT (*Internet of Things*) untuk memantau proses fermentasi secara cerdas dan real-time.
    *   *Teknologi*: Dart, Flutter, IoT.

3.  **[CSR Stunting Anak (Dashboard & App)](https://github.com/EoxikBlaze)**
    *   *Deskripsi*: Sistem monitoring gizi dan tumbuh kembang balita desa binaan CSR PAMA yang terintegrasi standar WHO untuk klasifikasi stunting otomatis berbasis Z-Score.
    *   *Teknologi*: Laravel REST API (Backend) & Flutter (Client Bidan App).

4.  **[website_portal_pelayanan](https://github.com/EoxikBlaze/website_portal_pelayanan)**
    *   *Deskripsi*: Portal web untuk mengintegrasikan dan mempermudah berbagai pelayanan administrasi secara terpusat.
    *   *Teknologi*: PHP, HTML, CSS.
